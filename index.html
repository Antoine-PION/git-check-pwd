Repérez les secrets dans l’historique Git

Analysez les ajouts de commits d’un dépôt ou des dépôts accessibles d’une organisation GitHub.

Nouvelle analyse

Votre jeton est utilisé uniquement dans ce navigateur et transmis directement à GitHub. Il n’est envoyé ni au serveur qui héberge cette page ni à un autre service. Préférez un jeton à durée limitée avec les droits de lecture minimaux.

Format attendu : propriétaire/nom-du-dépôt.

Le jeton doit pouvoir lire les métadonnées et le contenu des dépôts. Pour une organisation, il doit également permettre d’en lister les dépôts.

Rapport

Résultats de l’analyse

Les branches actuellement accessibles sont parcourues. Seules les lignes ajoutées visibles dans les patchs transmis par GitHub sont inspectées. GitHub peut omettre certains patchs, notamment pour les très gros commits; les limites et erreurs d’accès apparaissent ci-dessous. Ce rapport ne garantit pas l’absence de secrets.

Les valeurs détectées sont masquées dans le rapport. Vérifiez et révoquez tout secret exposé.
