Git Check Pwd

Repérez les secrets dans l’historique Git

GitHub ou GitLab sont reconnus à partir de l’URL saisie. Analysez un dépôt ou un groupe accessible.

Nouvelle analyse

Votre jeton est utilisé uniquement dans ce navigateur et transmis directement à la plateforme et à l’hôte indiqués par l’URL. Utilisez uniquement une URL de confiance et un jeton à durée limitée doté des droits de lecture minimaux.

Collez l’URL HTTPS du dépôt. GitHub, GitLab.com et les instances GitLab auto-hébergées sont pris en charge.

GitHub : accès en lecture au contenu; pour un groupe, accès en lecture aux dépôts. GitLab : scopes read_api et read_repository; pour un groupe, accès aux projets du groupe.

Rapport

Résultats de l’analyse

Les branches actuellement accessibles sont parcourues. Seules les lignes ajoutées visibles dans les patchs transmis par la plateforme sont inspectées. La plateforme peut omettre certains patchs, notamment pour les très gros commits; les limites et erreurs d’accès apparaissent ci-dessous. Ce rapport ne garantit pas l’absence de secrets.

Les valeurs détectées sont masquées dans le rapport. Vérifiez et révoquez tout secret exposé.
